# Build Checklist (No Source Code)

## Visual assets
- [ ] Replace cropped logo references with a clean SVG/vector logo.
- [ ] Add a dedicated signup hero illustration if a different composition is desired.
- [ ] Export consistent SVG icons for all interface and feature icons.
- [ ] Add licensed font files or load the chosen font through an approved provider.
- [ ] Optimize large images and prepare responsive crops.

## Screens and states
- [ ] Login page
- [ ] Signup page
- [ ] Mobile/tablet responsive layouts
- [ ] Password show/hide
- [ ] Empty, focused, invalid, loading, and disabled form states
- [ ] Password mismatch and weak-password feedback
- [ ] Successful sign-in / registration feedback
- [ ] Forgot-password screen or flow
- [ ] Terms of Service and Privacy Policy pages

## Authentication and security
- [ ] Choose an authentication provider or backend.
- [ ] Configure email/password sign-in and registration.
- [ ] Configure Google OAuth credentials and allowed redirect URLs.
- [ ] Add email verification and password reset.
- [ ] Add server-side validation, rate limiting, and abuse protection.
- [ ] Never put secrets or private API keys in frontend assets.
- [ ] Define session handling, sign-out, and protected routes.

## Quality
- [ ] Test keyboard-only navigation and screen-reader labels.
- [ ] Check color contrast and visible focus indicators.
- [ ] Test on current desktop and mobile browsers.
- [ ] Test at narrow widths and browser zoom.
- [ ] Verify links, legal copy, and error handling.
