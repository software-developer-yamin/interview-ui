# Supporting Services and Decisions

These are planning items, not configured services.

1. Authentication: choose a service such as Supabase Auth, Firebase Authentication, Auth0, or a custom backend.
2. Google sign-in: create OAuth credentials with the chosen provider and configure authorized origins and redirect URLs.
3. Email delivery: needed for verification and password-reset messages if the auth provider does not handle them.
4. Legal pages: publish Terms of Service and Privacy Policy before collecting account data.
5. Deployment: choose a hosting platform and configure environment variables securely.
6. Data handling: decide what user information is collected, how long it is retained, and how users can request account deletion.
7. Monitoring: configure error reporting and authentication-event monitoring without logging passwords or sensitive tokens.

No credentials, live integrations, or backend behavior are included in this asset pack.
