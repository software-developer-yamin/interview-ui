DATAPULSE UI ASSET PACK
=======================

This pack contains visual assets and implementation planning material for the DataPulse login and signup pages based on the supplied screenshots.

FOLDER GUIDE
------------
images/
  hero-analytics-mountain.png
  Generated cinematic mountain/analytics hero artwork. Use as a background or visual layer; position and crop responsively.

logo/
  datapulse-wordmark-login-reference.png
  datapulse-wordmark-signup-reference.png
  datapulse-mark-reference.png
  Cropped references from the supplied screenshots. These are visual references, not clean vector master artwork. Recreate/trace a clean logo for production use and confirm brand rights.

icons/
  Reserved for exported SVG/PNG icon files. The design calls for shield, lightning, chart, mail, lock, eye, arrow, user, and Google sign-in icons. Prefer a consistent icon set such as Lucide for interface icons; use Google's official branding assets for Google sign-in.

fonts/
  Reserved for licensed font files. Suggested font: Inter (or a close modern sans-serif). Obtain font files from the official source and check its license before bundling.

design/
  design-specifications.md
  color-palette.txt

references/
  login-reference.png
  signup-reference.png

documentation/
  asset-index.md
  build-checklist.md
  integration-requirements.md

NOT INCLUDED
------------
Application source code, backend implementation, working authentication, API keys, OAuth client IDs, database credentials, or production-ready vector logo files.
